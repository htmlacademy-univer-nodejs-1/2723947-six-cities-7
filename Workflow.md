# Как работать над проектом

## Окружение

Для удобства работы над проектом используются инструменты из **Node.js** и **npm**. Все необходимые настройки произведены. Убедитесь, что на рабочем компьютере установлен актуальный LTS релиз Node.js**. Актуальная версия **Node.js** указана в файле `package.json` в поле `node`. Затем, в терминале, перейдите в директорию с проектом и _единожды_ запустите команду:

```bash
npm install
```

Команда запустит процесс установки зависимостей проекта из **npm**.

### Сценарии

В `package.json` предопределено несколько сценариев.

#### Скомпилировать проект

```bash
npm run compile
```

Создаст директорию `dist` и скомпилирует проект.

#### Удалить скомпилированный проект

```bash
npm run clean
```

Удаляет директорию `dist`. Используется перед компиляцией.

#### Собрать проект

```bash
npm run build
```

Выполняет сборку проекта: удаляет ранее скомпилированный проект и компилирует заново.

#### Проверить линтером

```bash
npm run lint
```

Запуск проверки проекта статическим анализатором кода **ESLint**.

Линтер проверяет файлы только внутри директории `src`.

**Обратите внимание**, при запуске данной команды, ошибки выводятся в терминал.

#### Запустить ts-модуль без компиляции

```bash
npm run ts -- <Путь к модулю с ts-кодом>
```

Пакет `ts-node` позволяет выполнить TS-код в Node.js без предварительной компиляции. Используется только на этапе разработки.

#### Запустить проект

```bash
npm start
```

В процессе запуска проекта будет выполнен процесс «Сборки проекта» и запуска результирующего кода.

#### Запустить CLI

```bash
npm run cli -- --help
npm run cli -- --version
npm run cli -- --import ./mocks/offers.tsv
npm run cli -- --generate 100 ./generated-offers.tsv http://localhost:3000/offers
```

Без параметров CLI показывает справку. Команда `--import` читает TSV потоково и выводит разобранные предложения в консоль. Первая строка может содержать названия столбцов. Поля разделяются табуляцией; фотографии и удобства внутри поля разделяются точкой с запятой. Порядок столбцов приведён в `mocks/offers.tsv`. `authorEmail` указывает на автора предложения. Команда `--generate <n> <filepath> <url>` получает заготовки по указанному URL и потоково записывает `n` случайных предложений в новый TSV-файл с заголовком. `n` — положительное целое число. Существующий файл не перезаписывается. Фотографии, город и координаты берутся из одной заготовки; дата, рейтинг, стоимость, тип жилья, вместимость и удобства выбираются случайно. Избранное изначально выключено. Комментарии не генерируются.

Обе команды учитывают скорость записи: даже файлы больше 2 ГБ обрабатываются без загрузки целиком в память. Импорт выводит каждое предложение отдельной строкой JSON и итоговое количество. Ошибки чтения, записи, HTTP и формата завершают CLI с ненулевым кодом. Для защиты от повреждённых файлов длина одной строки ограничена 64 КиБ. Сгенерированные `*.tsv` исключены из Git; `mocks/offers.tsv` остаётся учебным примером.

#### Проверить CLI автоматическими тестами

```bash
npm test
```

Собирает проект и проверяет генерацию, импорт, ошибки и сохранение существующих файлов. Тесты самостоятельно запускают временный HTTP-сервер на свободном локальном порту.

#### Запустить тестовый REST API

```bash
npm run mock:server
```

Запускает JSON-server с шестью заготовками из `mocks/mock-server-data.json`. Ресурс для генератора: `http://localhost:3000/offers`. Чтобы изменить порт, выполните `npm run mock:server -- --port 3001` и передайте генератору соответствующий URL.

## Запуск проекта

1. Установите Node.js версии 18 или новее и зависимости командой `npm install`.
2. В первом терминале запустите `npm run mock:server`.
3. Во втором терминале выполните `npm run cli -- --generate 100 ./generated-offers.tsv http://localhost:3000/offers`.
4. Импортируйте данные: `npm run cli -- --import ./generated-offers.tsv`.

На данном этапе база данных и переменные окружения для CLI не требуются: адрес JSON-сервера и путь к файлу передаются аргументами.

### Проверка большого файла

После сборки (`npm run build`) можно запускать CLI напрямую, чтобы не пересобирать его перед каждой командой:

```bash
node dist/cli.js --generate 5000000 ./large-offers.tsv http://localhost:3000/offers
node dist/cli.js --import ./large-offers.tsv > /dev/null
```

Получится файл больше 2 ГБ. Для просмотра итога вместе с последними предложениями в Unix можно выполнить `node dist/cli.js --import ./large-offers.tsv | tail -n 3`. Вывод миллионов предложений в терминал замедляет проверку, поэтому для измерения памяти лучше перенаправлять его в `/dev/null`. После проверки большой файл можно удалить. Эти данные не нужно коммитить.

## Структура проекта

### Директория `src`

Исходный код проекта: компоненты, модули и так далее. Структура директории `src` может быть произвольной.

### Файл `Readme.md`

Инструкции по работе с учебным репозиторием.

### Файл `Contributing.md`

Советы и инструкции по внесению изменений в учебный репозиторий.

### Остальное

Все остальные файлы в проекте являются служебными. Пожалуйста, не удаляйте и не изменяйте их самовольно. Только если того требует задание или наставник.
